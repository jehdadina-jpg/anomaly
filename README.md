# ANOMALY TERMINAL

> AI-Powered Stock Market Analysis & Anomaly Detection Platform

## Overview

Anomaly Terminal is a Bloomberg-inspired stock market analysis platform that combines technical analysis with machine learning to detect unusual market behavior and generate AI-powered Buy, Hold, and Sell recommendations.

The platform analyzes historical stock data using multiple anomaly detection models and presents the results through a clean terminal-style interface.

---

## Features

- 📈 Bloomberg-inspired trading terminal UI
- 🔍 Stock search and watchlist
- 📊 Historical price charts
- 🤖 AI-powered Buy/Hold/Sell recommendations
- ⚡ Multi-model anomaly detection
- 📉 Technical analysis indicators
- 🧠 Explainable AI insights
- 📋 Ensemble model consensus
- 🌙 Modern dark terminal interface

---

## Machine Learning Models

The anomaly detection engine uses an ensemble of:

- Isolation Forest
- One-Class SVM (OC-SVM)
- Local Outlier Factor (LOF)
- Autoencoder

Each model independently analyzes the stock before contributing to the final recommendation.

## How It Works

1. Fetch historical stock market data.
2. Calculate technical indicators.
3. Run anomaly detection using multiple ML models.
4. Combine the results using an ensemble approach.
5. Generate Buy, Hold, or Sell recommendations.
6. Display everything in a Bloomberg-style dashboard.
